Selected work in backend systems, databases, AI-agent tooling, and data analysis.

## Projects

- [[projects/lectio-lab|Lectio Lab — ILIAS for AI Agents]] — A local MCP integration that lets University of Tübingen instructors publish course material and post grades to ILIAS from their AI agent, with verified writes and no stored passwords.
- [[projects/procora|Procora — One Python API for Stored Procedures]] — A typed Python library for discovering and calling stored procedures across SQL Server, PostgreSQL, and MySQL through one portable interface.
- [[projects/pixdb|PixDB — Image Analytics for DuckDB]] — a C++ DuckDB extension for querying image metadata and ASCII renderings, with visual features and vector search planned next.
- [[projects/duckdb-recursive-features|Distance-Vector Routing with DuckDB]] — A controlled research experiment comparing standard recursive CTE execution with DuckDB `USING KEY`.
- [[projects/ai-search-systems|AI & Search Systems]] — Information retrieval, ranking, and scalable backend design.
- [[projects/data-literacy-eeg|Household Resources and Neural Control]] — A team data-science study linking food insecurity to EEG attention markers, with an interactive Streamlit dashboard.
- [[projects/interaction-techniques|Interaction Techniques & Technologies]] — Webcam, sensor and audio interaction prototypes, including a replication of MatchPoint (UIST 2017) touchless pointing.

## Earlier work

- [[projects/early-open-source|Early Open Source (2021–2023)]] — An OpenCV answer-sheet scanner, Persian calendar and number utilities, and a Django social-media automation service.
